# 2.3.0 共享记忆离线验证环境与评测边界

2026-10-13，第二轮共享记忆优化在 Windows、Python 3.11.5、SQLite 3.41.2 本机验证。
49 项隔离 unittest 通过，覆盖部分索引复用、检索中并发修改、更正与范围、2.2.0 缓存兼容、元数据哈希条件保存、BOM/CRLF 与未知字段保留、真实语料标签验证、预算和无答案问题。
公开仓库的人工核对问题集另经实际命令验证：26 个问题中 23 个有标注答案，前三个展示候选全部包含目标；历史禁选命中为零。三个无答案问题中仍有两个出现本地候选。
验证边界：回归测试的模型接口由模拟响应与本地 HTTP 服务提供，不读取真实 key、不调用外部模型。公开问题集这里使用 local 模式；上述命中不能当作完整云端模型准确率。
global toolkit 单独运行同一测试通过，其中真实仓库历史测试因工具包不分发历史而跳过。仅工具与协议升级不会要求重算相同嵌入输入。
