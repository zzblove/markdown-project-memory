# 共享记忆服务修复方案

背景：用户要求修复 shared-memory-1.0 的共享记忆服务，并同意在 D:/zzb/memory 启用项目共享记忆协议。
决策：保留现有 MCP 工具名称和 REST 路由；原文与索引使用原子事务，单进程共享连接和向量缓存由同一可重入锁保护；原文先保存，外部嵌入交给后台工作线程；摘要更新采用版本条件写入并保存历史。
理由：避免已确认的误删除、不完整提交、缓存遗漏和摘要覆盖，同时保持本机部署简单。
被否方案：不在本次修复引入独立向量数据库或分布式任务队列；当前目标是单机多 Agent 服务，先保证可靠性。
验证策略：测试使用临时数据库、离线配置及临时端口，避免覆盖真实 guide 或调用真实外部 API。
