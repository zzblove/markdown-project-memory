# 第二轮优化优先级与共享边界

背景：用户要求继续降低共享记忆的资源占用、提高检索准确度，并同意先推进真实问题评测、旧记忆元数据整理、按文件增量检索。
结论：保留 Markdown 事实源、标准库实现、同一目录的多 agent 共享边界。评测采用人工核对原文的真实问题；旧记忆只补摘要、适用范围和依据，维护不代表重新核实事实；已变化文件使用当前正文，未变化文件仍可复用向量。
理由：优先验证是否找对内容，再改进输入质量与更新期间的可用性。新功能不应强迫用户下载本地模型，也不应因工具版本更新而重算未变化的嵌入。
被否方案：本轮不引入独立向量数据库、本地大模型、自动提取全部聊天或未经核对的语义合并；跨项目共享仍须显式配置。
发布边界：私有项目的正文和评测问题保留在本机；公开仓库仅包含公开历史及通用回归样例。
